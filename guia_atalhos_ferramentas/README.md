# Guia de Atalhos e Ferramentas

Voltar ao [Glossário de Conceitos](README.md) 

Este guia foi pensado como uma colinha para ajudar a ir construindo interfaces no Figma de forma mais rápida. Como o Figma possui várias ferramentas e atalhos, é meio assustador e quase impossível lembrar de todos no começo,
mas, conforme você vai utilizando-os, eles irão acabar ficando na memória. Esperamos que esse guia auxilie nisso:

## 1. Navegação 

- **Mão (Pan):** Segure `Barra de Espaço` + `Clique e arraste` para empurrar a tela.
- **Zoom In/Out:** `Ctrl` + `Rolagem do Mouse` (ou use as teclas `+` e `-`).
- **Zoom para caber tudo:** `Shift + 1` (Dá uma visão geral de todas as telas).
- **Zoom no objeto selecionado:** `Shift + 2` (Foca instantaneamente no item que você selecionou).

## 2. Kit de Construção

- **Frame (F):** O contêiner principal. Sempre desenhe suas telas dentro de um Frame.
- **Retângulo (R):** Base para botões, cards e divisores.
- **Elipse (O):** Para ícones circulares e fotos de perfil.
- **Texto (T):** Clique em qualquer lugar para começar a digitar.
- **Mover (V):** A seta padrão para selecionar e arrastar objetos.

## 3. Organização

- **Agrupar Seleção:** `Ctrl + G` (Cria um Grupo).
- **Transformar em Frame:** `Ctrl + Alt + G` (Cria um Frame ao redor dos itens).
- **Renomear em Massa:** `Ctrl + R`. Se selecionar vários itens, você pode usar expressões para renomear todos de uma vez 
- **Esconder/Mostrar:** `Ctrl + Shift + H` (Esconde um elemento sem deletá-lo).
- **Travar/Destravar:** `Ctrl + Shift + L` (Impede que você mova um item por acidente).

## 4. Coisas do Layout

- **Criar Auto Layout:** `Shift + A` (Transforma a seleção em um contêiner Flexbox).
- **Remover Auto Layout:** `Alt + Shift + A`.
- **Criar Componente:** `Ctrl + Alt + K` (Transforma o item em uma "Classe" mestre).
- **Extrair (Detach) Instância:** `Ctrl + Alt + B` (Quebra o vínculo com o Componente Mestre).

## 5. Alguns outros truques

- **A Trena do Dev:** Selecione um objeto e segure a tecla `Alt`. Ao passar o mouse sobre outros elementos, o Figma mostra a distância exata em pixels entre eles.
- **Copiar/Colar Estilos:** `Ctrl + Alt + C` e `Ctrl + Alt + V`. Copia apenas as propriedades visuais (cor, sombra, borda) de um objeto e aplica em outro.
- **Duplicação Rápida:** Segure `Alt` e arraste qualquer objeto para criar uma cópia idêntica.
- **Busca Global:** `Ctrl + /`. Abre uma barra de pesquisa onde você pode digitar o nome de qualquer comando, ferramenta ou plugin para executá-lo na hora.

## 6. DevMode

- **Alternar Dev Mode:** `Shift + D` (Muda instantaneamente para a visão de inspeção de código).
