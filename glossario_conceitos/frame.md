# Frame

Voltar para o [Glossário](README.md).

Um Frame (ou no bom e velho português um Quadro), é um dos conceitos mais importantes do Figma. Se fossemos comparar com código, ele seria a tag `<div>` do HTML, ou seja, ele agrupa elementos, mas possui suas próprias regras de comportamento, tamanho e estilo.

## Como funciona?

Aqui estão algumas características importantes dos Frames: 

- **Clip Content**: O Frame funciona como uma janela, ou seja, você pode ter um desenho gigante dentro dele, mas se a opção Clip Content estiver ativada, ele vai esconder (cortar visualmente) tudo o que vazar para fora de suas bordas. Algo que é muito bom para fazer listas roláveis ou esconder partes de uma imagem.

- **Limites Independentes**: Se você aumentar o tamanho de um Frame, os elementos dentro dele não vão esticar junto automaticamente (a menos que você configure as Constraints para isso).

- **Grids e Layouts**: Você só consegue adicionar colunas, linhas de grade (Grids) ou usar o poderoso Auto Layout se os seus elementos estiverem dentro de um Frame.

- **Eles podem ser aninhados**: Você pode colocar Frames dentro de Frames! (Sim incrivel não é !? :O ) Por exemplo: a tela inteira do celular é um Frame. O cabeçalho é outro Frame dentro dela. O botão dentro do cabeçalho é um terceiro Frame. Podemos ter N Frames com lim N -> ♾️ (quem disse que cálculo não serve pra nada?)
