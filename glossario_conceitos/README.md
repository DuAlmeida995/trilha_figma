# Glossário de Conceitos

> Esse espaço é dedicado a definições e explicações dos principais conceitos relacionados ao nosso querido Figma. Aqui, você encontrará tanto termos técnicos quanto suas descrições para ajudar a esclarecer possíveis dúvidas que você possa ter, ou até mesmo para relembrar o significado por trás de cada um desses conceitos.

## Sumário

* [Frame](frame.md) — As pranchetas de desenho e contêineres principais.
* [Group](group.md) — Organização básica de elementos.
* [Layer](layer.md) — A hierarquia e o empilhamento de camadas.

* [Style](style.md) — Trabalhando com variáveis de cores, textos e efeitos.
* [Component](component.md) — Criando elementos reutilizáveis (Classes).
* [Instance](instance.md) — Utilizando cópias de componentes (Objetos).
* [Variant](variant.md) — Gerenciando estados e propriedades (Props).

* [Auto Layout](auto_layout.md) — O "Flexbox" do Figma para designs dinâmicos.
* [Constraints](constraints.md) — Definindo regras de ancoragem e redimensionamento.


* [Prototype](prototype.md) — Dando vida ao projeto com fluxos clicáveis e animações.
* [Dev Mode](dev_mode.md) — A ferramenta de inspeção para desenvolvedores extraírem código.
* [FigJam](figjam.md) — O espaço para brainstorming e planejamento de fluxogramas.
